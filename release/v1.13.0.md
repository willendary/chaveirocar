# ChaveiroCar v1.13.0

O formulário Android busca o modelo ao digitar ou confirmar pela câmera uma placa válida. Veículos já atendidos usam o histórico local. Para veículos novos, a empresa precisa de acesso à API e o servidor precisa da chave Placadata configurada em `PLACADATA_API_KEY`. O modelo pode ser informado manualmente quando a consulta estiver indisponível.
