# ChaveiroCar v1.13.1

## Consulta de modelo pela placa sem API Key

- Substituída a consulta anterior via Falcon Data Hub pela **Parallelum FIPE — Busca por placa (Alpha)**, sem necessidade de API Key no app ou no servidor.
- Placas brasileiras antigas e Mercosul: marca, modelo e ano preenchidos automaticamente quando a consulta encontra o veículo.
- Veículos já atendidos continuam utilizando o histórico local antes de consumir consultas externas.
- Novo cache de resultados técnicos no **Turso** por 90 dias para economizar a cota. Nenhum dado de proprietário ou chassi é armazenado.
- Mensagens de erro específicas para placa não encontrada, indisponibilidade e cota esgotada. Preenchimento manual continua disponível.

**Atenção:** o endpoint gratuito sem autenticação oferece somente **5 consultas por mês**, está em fase Alpha e depende da disponibilidade do fornecedor. Não há garantia de busca para toda placa nem de consultas ilimitadas. O app continua funcionando para cadastro de modelo manualmente quando a cota acabar.

A API do ChaveiroCar precisa estar atualizada com a migração `004_cache_consultas_placa.sql`; a implantação Render configurada em `main` é automática após o merge. A variável antiga `FALCON_DATA_HUB_API_KEY` não é mais utilizada.
