# ChaveiroCar v1.16.4

Integração da fonte gratuita Puxa Placa no backend, com leitura de páginas HTML que realmente apresentam o modelo.

- **Caso real validado:** NAQ2405 = FIAT / MOBI DRIVE / 2018 (ano-modelo). Também foram identificados RIZ1B98 e CIX6290 em acesso HTTP real do GitHub Actions.
- A resposta HTML é aceita apenas se confirmar a placa solicitada e tiver marca, modelo e ano em campos estruturados.
- Puxa Placa consultado após CarroFIPE e antes das outras fontes HTML.
- Respeito aos limites: intervalo de 4,5 segundos entre requisições ao Puxa Placa e pausa temporária de fontes com HTTP 403/429, sem contornar bloqueios.
- Histórico da equipe e cache Turso continuam prioritários; Catálogo FIPE permanece disponível.

**Limitação conhecida:** Puxa Placa retornou HTTP 429 após três consultas espaçadas de aproximadamente 4 segundos. Esta versão melhora o reconhecimento, mas não promete consulta ilimitada ou cobertura de todas as placas. Para 200+ consultas por mês com previsibilidade, é necessária fonte autorizada.
