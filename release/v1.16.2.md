# ChaveiroCar v1.16.2

Atualização de instalação com a correção de consulta automática de placas integrada ao backend principal.

- Android 1.16.2 (versionCode 33) e Windows 1.16.2.
- Consulta pelo endpoint JSON de prévia gratuita do CarroFIPE, introduzida na correção #139, agora incorporada ao código principal do servidor.
- Falhas de provedor e respostas sem dados não serão apresentadas como se a placa não existisse.
- Permanecem as fontes alternativas, cache Turso, aproveitamento de histórico e preenchimento manual pelo Catálogo FIPE.

**Importante:** a API hospedada no Render precisa concluir a implantação da branch `main` com a correção. A prévia gratuita do CarroFIPE nem sempre apresenta marca/modelo/ano, inclusive para placas válidas; não há garantia de preencher todas as placas automaticamente.

Referência: https://github.com/willendary/chaveirocar/pull/139
