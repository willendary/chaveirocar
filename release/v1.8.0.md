## Novidades da versão 1.8.0

- **Migração completa para a API + remoção definitiva do legado Google Drive (`#40`)**:
  - Botão **Migrar todo o histórico local para a empresa** em Ajustes → Conta ChaveiroCar, enviando atendimentos, fichas técnicas e fotos para a API de forma idempotente com resumo detalhado de conciliação.
  - Exportação e importação direta de cópia de segurança em arquivo `.zip` em Ajustes, independente da nuvem.
  - Remoção total do código e escopos legados do Google Drive (`drive.appdata`), mantendo apenas a autenticação limpa de identidade Google (`IdentidadeGoogle`).
- **Aplicativo iOS para iPhone e iPad (`#43`)**:
  - Novo projeto `ios/` em Swift / SwiftUI (`ChaveiroCarCore` + `ChaveiroCarApp` + `ChaveiroCarTests`) integrado à mesma API (`/api/v1`), com sessão no Keychain, cache offline-first, resolução de conflitos, segmentos Automotivo e Residencial, placa opcional + modelo obrigatório, fichário por segmento e anotador de fotos com setas.
- **Conclusão do Épico Multiplataforma (`#36`)**:
  - Paridade entre Android, iOS, Windows e API central com Turso e storage autenticado de fotos, além de correção na migração SQLite (`v8`) para bancos criados antes da tabela de atendimentos.
