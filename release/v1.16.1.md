# ChaveiroCar v1.16.1

Correção da consulta automática de placas.

- A integração com o CarroFIPE passa a ler a resposta da prévia gratuita carregada pelo site. Antes, lia apenas o HTML inicial do formulário.
- Corrigida a mensagem de placa não encontrada quando o serviço está indisponível ou não fornece dados do veículo.
- Mantidos o aproveitamento do histórico, o cache das consultas, as fontes alternativas e o preenchimento manual pelo Catálogo FIPE.
- Dados de demonstração e respostas inconsistentes são descartados.

A disponibilidade de marca, modelo e ano depende das fontes consultadas. Se a prévia gratuita não fornecer esses campos, preencha o modelo manualmente ou pelo Catálogo FIPE. Esta versão não garante encontrar todas as placas.

Disponível para Android e Windows. A correção da consulta também depende da atualização da API no servidor.
