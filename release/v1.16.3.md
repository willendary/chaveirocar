# ChaveiroCar v1.16.3

Correção de limite em consultas de placas e melhor aproveitamento do histórico do usuário/equipe.

- A versão anterior limitava o backend a 60 tentativas externas/hora; uma única placa podia consumir até quatro, bloqueando as seguintes. O orçamento agora é de 1.200 tentativas/hora por processo, sem ultrapassar proteções dos fornecedores.
- O backend reutiliza os modelos dos atendimentos já registrados na mesma empresa, inclusive por outro membro da equipe, sem consultar fornecedores e sem misturar dados de empresas distintas.
- Consultas autenticadas por sessão: até 30/min no endpoint de placas.
- Android mostra mensagem mais clara quando a fonte gratuita não informa os dados e oferece **Tentar consulta novamente**.
- Bateria com 240 placas **sintéticas** (200 resultados via prévia, 20 via HTML alternativo, 20 indisponíveis), com chamadas externas simuladas e verificação de cache, erros e isolamento entre empresas. O teste não mede a cobertura de placas reais.

**Limitações:** marca/modelo/ano não podem ser garantidos quando a fonte não oferece esses dados de maneira pública. O serviço mantém respeito a bloqueios, CAPTCHA e HTTP 403/429. O app permite completar os dados pelo Catálogo FIPE. A atualização do backend no Render depende da implantação da branch main.

Referência técnica: correção de lote e histórico de placas.
