- Aplicada a **logo oficial do ChaveiroCar** em todas as plataformas e ativos de design:

## Consulta automática de veículos por placa sem API Parallelum (#135)

- Removida a chamada à API gratuita da **Parallelum** (`fipe.parallelum.com.br/api/v2/plates`), que limitava a 5 consultas mensais e exibia erro de cota mensal esgotada.
- A busca automática por placa agora opera **exclusivamente** por leitura direta de páginas HTML públicas, ativada por padrão (`PLACAS_WEB_ATIVAS=true`), usando **CarroFIPE** (`carrofipe.com.br`) como fonte principal, seguida por **PlacaIPVA**, **KePlaca** e **PlacaFIPE**.
- Mantidos o cache de 90 dias no Turso (apenas `marca`, `modelo` e `ano`), o reaproveitamento do histórico local no Android, o respeito a bloqueios HTTP 403/429/CAPTCHA (sem contornos) e o preenchimento manual offline.
- Atualizada a mensagem de aviso HTTP 429 no Android para não exibir mais alerta de cota mensal gratuita.
